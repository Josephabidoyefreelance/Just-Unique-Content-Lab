Your API keys

Stored only in this browser's local storage. Never sent anywhere except straight to each provider when you generate something. If you're building this for customers, each person pastes in their own keys, this app never sees or holds them centrally.

Switch the dropdown any time, each provider keeps its own saved key. Only the one selected here shows up as active, so the panel doesn't fill up with keys you're not using. On Grok: the chat endpoint is confirmed from xAI's own docs, but I have not test run it against a live key, and their live "list models" endpoint is unconfirmed, so "Refresh models" may fail silently for Grok and just keep the two model names built in here.
Note on Google: the same Google AI key above also unlocks Veo 3 video in the Video tab, no separate key needed for that. Note on Higgsfield: their API needs two values, a Key ID and a Key Secret, both from your Higgsfield dashboard, not one combined key.
Before you rely on this: Anthropic officially supports calling its API straight from a browser. OpenAI, Google, ElevenLabs, and Replicate may or may not allow that depending on your account and their current policy, I have not verified each one live. If a generate button fails with a network or CORS error, that is why, not a bug in this page. The fix is a small proxy server relaying the request, tell me and I will build it.
