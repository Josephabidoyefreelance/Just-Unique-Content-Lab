Just Unique Content Lab

One studio for script, voice, image, and video. Bring your own API keys, pick your own models.

Your API keys

Stored only in this browser's local storage. Never sent anywhere except straight to each provider when you generate something. If you're building this for customers, each person pastes in their own keys, this app never sees or holds them centrally.

You only need the keys for the tabs you use. Anthropic, OpenAI, or Google, pick any one, for Script and Idea. ElevenLabs for Voice. Replicate for Image and Video. Wavespeed is saved here for when you send me its exact API docs so I can wire it for real instead of guessing.
Before you rely on this: Anthropic officially supports calling its API straight from a browser. OpenAI, Google, ElevenLabs, and Replicate may or may not allow that depending on your account and their current policy, I have not verified each one live. If a generate button fails with a network or CORS error, that is why, not a bug in this page. The fix is a small proxy server relaying the request, tell me and I will build it.

Idea

Pick a niche and an angle, generate one full concept: a hook, a subtitle, a caption, and how it should be voiced. Everything after this tab pulls from what you generate here.

There is no API, anywhere, that generates more than a few seconds of continuous AI video per request. A long length here means a longer script and more scenes stitched together deliberately, not one uninterrupted AI shot. Anyone claiming otherwise is not being straight with you.
Keeping the same character looking identical across separate generated scenes is a known limitation of every current image and video model, not something this tool can guarantee. Treat these as strong direction for each shot, not a locked in actor.
On uniqueness: this checks your hook against only the ideas you have generated before in this tool. No tool anywhere can verify a prompt has never been used by anyone else online, there is no database of that. Be skeptical of any product that claims otherwise.
